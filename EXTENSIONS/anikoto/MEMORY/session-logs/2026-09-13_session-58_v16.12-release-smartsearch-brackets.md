## 2. Root cause 1 — Test Connection HTTP 400 (PROVEN with the user's test key)

The internal test key (SECRETS.md, sandbox-only) is geo-blocked from the sandbox
(`400 FAILED_PRECONDITION "User location is not supported"`), but the geo check runs AFTER
payload validation, so error precedence experiments still work:

| Request (v1beta `generateContent`) | Result |
|---|---|
| `gemini-3.5-flash-lite` + body WITH `thinkingConfig.thinkingBudget=0` (the old request) | **400 INVALID_ARGUMENT "Request contains an invalid argument."** ← exactly the user's toast |
| `gemini-3.5-flash-lite` / `gemini-3.1-flash-lite` / `gemini-3.8-flash` + body WITHOUT thinkingConfig | 400 FAILED_PRECONDITION (location) → payload **valid** |
| bogus model + same body | **404 NOT_FOUND** → the three 3.x ids all EXIST |

**Conclusion:** the 3.x Gemini family rejects `thinkingConfig.thinkingBudget` (2.5-era field)
with a bare INVALID_ARGUMENT that never mentions "thinking" — so session 57's message-content
retry never fired. Fix: thinkingConfig is now attached ONLY for `gemini-2.5*` models; on any
400 with thinkingConfig attached we retry once without it.

## 3. Root cause 2 — "Google answered but no title could be read"

The user's pasted response ends with:
`The anime you are looking for is Alya Sometimes Hides Her Feelings in Russian (Japanese title: Tokidoki Bosotto Russia-go de Dereru Tonari no Alya-san).`

Traced through the v16.13 extractor line by line:
- **S2** (`looking\s+for … is X`) caps the match at 80 chars INCLUDING the parenthetical —
  this sentence is ~118 chars, so the regex never terminates in range → no match.
- **S7** line scan caps lines at 90 chars (same miss) AND skips lines containing " is ".
- S1/S3/S4/S5/S6 don't fit this phrasing. → every strategy failed.

**Fixes (validated 3/3 on real responses — `/home/z/probe-s58/validate_new_extractor.py`):**
1. **S0 bracket strategy (new, strongest)** — lenient `[{[ Title ]}]` parser
   (`\[\{\[([^\]\}]{2,120}?)[\]\}]`), tolerates AI Mode's imperfect compliance seen live:
   `[{[Naruto]}]`, `[{[\nNaruto , }] :`. Skips empty captures (the query echo carries a
   literal `[{[ ]}]` from the instruction) and lowercase single words.
2. **S1/S2 widened** — capture class now stops at `(` (`[^\n.!?(]`), cap 80 → 100; the
   parenthetical no longer inflates the match. The user's failing sentence now yields
   "Alya Sometimes Hides Her Feelings in Russian" via S2.
3. **S2c (new)** — "the anime/series/show is X".
4. **S6b (new, late)** — "Japanese title: X" romaji fallback.
5. **S7** — parenthetical stripped BEFORE length checks, raw line cap 90 → 120.

**Bracket instruction (user's idea, both engines):**
- Gemini: prompt now demands `[{[Title]}]` output (parsed by S0 first, `cleanTitle` fallback).
- Google: SHORT suffix appended to the CLEAN query —
  `" (in your answer, wrap the anime title in [{[ ]}] brackets)"`. Verified live 2026-09-13:
  AI Mode honored it (`Here is a quick overview of the iconic series [{[\nNaruto , }] :`).
  NEVER send the whole LLM prompt as the query (that was the v16.12 bug — session 57).

Live probes: `/home/z/probe-s58/google_bracket_probe.py` (scrapling StealthyFetcher).
2 of 3 probes hit Google's 429 CAPTCHA wall from the sandbox (IP 47.57.x.x — flaky per-IP);
the third got a full AI Mode capture. Confirms the block-classifier markers still matter.

## 6. ★ Lessons

1. **Gemini 3.x does not accept the 2.5-era `thinkingConfig.thinkingBudget`** — and the error
   is a bare INVALID_ARGUMENT with no "thinking" keyword. Model-family-gate request extras;
   never gate retries on error-message wording.
2. **Geo-blocked key ≠ unusable key**: FAILED_PRECONDITION (location) arrives AFTER payload
   validation and model lookup — a sandbox behind a geo wall can still verify request
   validity and model existence (404 = missing model, INVALID_ARGUMENT = bad payload,
   FAILED_PRECONDITION = payload fine).
3. **Cap regex/title heuristics on the TITLE, not the whole sentence** — Google AI Mode
   answers routinely append "(Japanese title: …)" which tripled the match length.
4. **Bracket conventions work**: AI Mode honors a short inline format instruction (verified
   live); make the parser lenient (imperfect closers, line breaks inside the brackets).
5. Google 429 CAPTCHA from datacenter IPs is flaky per-IP (2/3 blocked in one minute, same
   /16) — pace probes, retry later, and keep the block classifier.
